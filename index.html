🛡️ BCK Enterprise

Enterprise Backup & Disaster Recovery для сучасної інфраструктури. Альтернатива Veeam — повністю на Rust, з миттєвим відновленням VM та наскрізним шифруванням.

Потужні можливості

Движок, сховища, віртуалізація, хмара та комплаєнс — повний цикл захисту даних.

🚀

Instant Recovery

VM стартує прямо з бекапу через NFS/iSCSI. RTO — хвилини, а не години.

🔒

Шифрування з коробки

AES-256-GCM / ChaCha20-Poly1305 на клієнті. Дедyп SHA-256, стиснення LZ4/Zstd.

☁️

Будь-яке сховище

Local FS, S3, Azure Blob, GCS, Tape LTFS + SOBR-рівні та lifecycle.

🖥️

VMware / Hyper-V

CBT/RCT-трекінг змін, снапшоти, backup jobs через REST, SureBackup-перевірка.

🏢

Enterprise

M365, CDP, DR-failover, SSO (OIDC+LDAP), audit-log, SLA-звіти, мультитенантність.

📊

Веб-консоль + CLI

React Web UI, CLI, агент та proxy. REST :9440, gRPC :9441, PWA офлайн.

Встановлення за 30 секунд

Одна команда — і все працює. Оберіть свою ОС:

curl -fsSL https://raw.githubusercontent.com/ajjs1ajjs/BCK/main/scripts/install.sh | sudo bash

💡 На Linux/macOS потрібен sudo • На Windows — PowerShell від імені адміністратора
