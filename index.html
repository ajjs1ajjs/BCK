Можливості

🚀 Швидке відновлення

Миттєве відновлення даних з будь-якої точки в часі. Інкрементальні бекапи економлять місце та час.

🔒 Шифрування AES-256-GCM

Всі дані шифруються на боці клієнта перед передачею. Приватні ключі ніколи не покидають ваш сервер.

☁️ Гібридне зберігання

Підтримка локальних дисків, NAS, SAN та хмарних сховищ в одному рішенні.

📊 Веб-консоль

Сучасний веб-інтерфейс для керування бекапами, моніторингу та відновлення.

🔄 Автоматизація

Гнучке планування бекапів з підтримкою інкрементальних та диференційних копій.

📱 REST API + gRPC

Повний API для інтеграції з вашими інструментами та автоматизації.
